# Stealth AI System (Unity)

## 📌 Description
AI system for stealth-based game:
- Hearing & noise system
- Field of View detection
- Suspicion system
- State Machine AI
- Enemy types via ScriptableObjects

## 🧠 Features
- Finite State Machine (Patrol / Suspicion / Investigate / Chase / Return)
- Noise-based detection
- Vision cone (FOV)
- Suspicion level logic
- Enemy behavior via ScriptableObject
- Modular & scalable architecture

## 🎮 Tech
- Unity 2D
- C#
- Rigidbody2D
- ScriptableObjects
- LineRenderer (FOV / noise visualization)

## 📁 Structure
- Scripts/AI — enemy logic
- Scripts/Noise — sound system
- Scripts/Core — base systems
- ScriptableObjects — enemy configs
